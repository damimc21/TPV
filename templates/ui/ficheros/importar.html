      Formato de importacion

      Usa la plantilla basica para altas y actualizaciones de productos. Si un producto ya existe por nombre, se actualiza; si no existe, se crea.

      CampoRegla
      nombreObligatorio. Si ya existe, se actualiza el producto.
      departamentoObligatorio. Todo producto debe pertenecer a un departamento. Si no existe, se crea automaticamente.
      precioOpcional. Acepta punto o coma decimal. Si falta, se usa 0.00.
      activoOpcional. Acepta 1/0, si/no, yes/no, true/false o activo/inactivo. Cualquier otro valor se rechaza. Si falta, se importa como activo.
      nombre_facturaOpcional. Si falta, se usa el nombre del producto salvo que desactives esa opcion en la vista previa.
      nombre_comandaOpcional. Si falta, se usa el nombre del producto salvo que desactives esa opcion en la vista previa.
      color_boton / color_textoOpcional. Si vienen en una exportacion completa, se importan y se normalizan a formato #rrggbb. Si vienen vacios, se mantiene el color existente o se usa el color por defecto en productos nuevos.
      imagenesNo se importan desde esta plantilla. Se gestionan desde Catalogo.
      eliminadoNo se importa. La eliminacion se gestiona desde Catalogo.

      Usa la plantilla basica para altas y actualizaciones de articulos de inventario. Si un articulo ya existe por nombre, se actualiza; si no existe, se crea.

      CampoRegla
      nombreObligatorio. Si ya existe, se actualiza el articulo.
      categoriaOpcional. Si no existe, se crea automaticamente.
      unidadOpcional. Valores admitidos: ud, pack, caja, kg, g, l, ml. Si falta o no se reconoce, se usa ud.
      stock_actualOpcional. Si falta, se usa 0.
      stock_minimoOpcional. Si falta, se usa 0.
      proveedorOpcional.
      precio_compraOpcional. Si falta, se usa 0.

      El Excel incluye una hoja de instrucciones. En CSV, conserva la primera fila con los nombres de columna.
